# Static Astro and Starlight site

The documentation repository will be one static Astro application published to organization/user GitHub Pages. A custom Astro landing page will live alongside Starlight’s documentation shell; Markdown is the default content format, MDX is limited to reusable explanatory components, and a small CSS-variable-based customization layer will provide Mininet-IPLab branding without replacing Starlight’s documentation styling.

The site will use versioned static SVG/PNG/GIF assets, including the existing Web UI demo, rather than runtime topology rendering or a client-side application.
