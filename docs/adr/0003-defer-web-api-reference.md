# Defer API references

The first public documentation release will not include a Web API or Python API reference, and will not promise an LMS integration contract. The current Web API remains an implementation surface of the Web UI, coupled to its authentication, roles, sessions, and WebSockets; the Python exports likewise need an explicit supported-public surface before either should receive a compatibility promise.

When this scope is reopened, the current Web API reference, a stable external integration contract, and a supported Python API must be treated as separate decisions.
