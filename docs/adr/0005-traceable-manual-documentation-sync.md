# Traceable manual documentation synchronization

The initial documentation release uses manual prose curation rather than automated synchronization. To prevent the two repositories from becoming indistinguishable sources of truth, every stable page identifies the core release it describes, every `next` page identifies a core commit, and executable Lab Examples remain in the core repository rather than being copied into the documentation repository.

This is an intentionally temporary process choice; automation can be added later without changing the ownership boundary.
