<p class="doc-lede">Mininet-IPLab is a lightweight routing lab built on Mininet and FRR. Run BGP, OSPF, DHCP, DNS and RPKI
labs from the CLI or a web UI with in-browser terminals.</p>

Use this path if you are new to the project:

1. [Check the prerequisites](/docs/getting-started/prerequisites/) — prepare a Linux-capable host, Docker, and Open
   vSwitch.
2. [Run the Quick Start](/docs/getting-started/quickstart/) — start `static-lab` and observe a working route.
3. [Create a Lab](/docs/build-labs/) — turn a lesson plan into a Python Lab Example, or draw one in the browser with
   [Lab Authoring](/docs/build-labs/lab-authoring/).
4. [Add a feature](/docs/features/) — copy the exact authoring pattern for routing, RPKI, services, IPv6, containers,
   or ExaBGP.

Want to see what a running Lab looks like first? Browse the [Lab Example catalog](/docs/lab-examples/): all 14 Lab
Examples that ship with the core repository, with a screenshot of each one running in Web UI Mode.

## After your first Lab

- [Run a classroom](/docs/getting-started/classroom/) — start `mniplab serve` and configure Instructor/Learner access,
  with one shared Lab or a [Lab per Group](/docs/features/multi-lab/).
- [Browse the Reference](/docs/reference/) — find exact commands, settings, and public Python names.
- [Contribute](/docs/contribute/) — choose the right repository and run the project checks.

These pages document Mininet-IPLab `v0.1.0`. Use the version selector beside the site title to switch to the
documentation for another release.

Use the [core repository](https://github.com/mininet-iplab/mininet-iplab) for executable Lab Examples and the runtime
Web UI source.
